# Procedencia de recursos

- `mimi.png` y `dudu.png`: personajes proporcionados y preparados para este proyecto.
- `real_cookie.png`, `real_bag.png`, `real_vacuum.png` y `fallback_background.png`: recursos preparados para este proyecto.
- `mimi_dudu_original.wav`: pista original de respaldo incluida en este proyecto.
- Fondos descargados durante las ejecuciones: Pexels API. El workflow conserva el nombre del fotógrafo y la URL para añadir crédito en el caption.

No agregue a este repositorio audios comerciales descargados de terceros. La música en tendencia se asocia al Reel mediante el identificador autorizado que devuelve Meta.
